\# 大二早八人 | 作息与精力监控台



\##  项目简介

本作品基于“个人技术整合练习”要求，以“大二学生作息与精力管理”为主题，整合了页面、样式、交互、可视化及三维导览四大模块，形成统一看板。旨在用数据记录真实的大学生活，反思熬夜与早八带来的精力波动。



\##  运行说明（如何本地预览）

由于本项目使用了 `fetch` 加载 JSON 数据以及三维模块，无法直接双击 HTML 文件运行，请按以下步骤启动本地服务器：

1\. 打开终端（Git Bash 或 CMD）。

2\. 进入项目根目录（例如：`cd /d/campus-life-hub`）。

3\. 输入命令启动本地服务器：
